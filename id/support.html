Hubungi kami

Kirim email ke khangazun@gmail.com. Tautan ini membuka pesan dengan templat singkat. Jika sebuah file menampilkan informasi yang salah atau tidak lengkap, sebutkan jenis file tersebut dan dari mana asalnya; mohon jangan mengirim file yang bukan milik Anda.

Pertanyaan umum

File apa saja yang dapat dibaca Probette?

Video: MP4, MOV, M4V, 3GP, MP4 terfragmentasi, Matroska (MKV), WebM, MPEG-TS, M2TS, dan AVI. Audio: MP3, FLAC, Ogg Vorbis dan Opus, WAV, RF64, BW64, AIFF, CAF, M4A, AAC, AC-3, E-AC-3, dan DTS. Gambar: JPEG, HEIC, AVIF, PNG, APNG, GIF, WebP, TIFF, DNG, dan BMP. Probette mengenali file dari isinya, bukan dari namanya.

Apa arti lencananya?

4K, 1080p, dan sejenisnya berasal dari ukuran gambar. HDR10 adalah gambar PQ 10 bit atau lebih; HDR10+ menambahkan metadata dinamis; HLG adalah hybrid log-gamma; Dolby Vision menampilkan profilnya (8.1 berarti lapisan dasar yang kompatibel dengan HDR10). Atmos adalah audio berbasis objek dari Dolby dalam E-AC-3.

Di mana bidang mentahnya?

Klik (atau ketuk) sebuah trek untuk menampilkan tabel setiap bidang yang dibaca Probette, persis seperti di dalam file. Bagian Kontainer menampilkan struktur file itu sendiri.

Mengapa tidak ada peta untuk lokasi foto?

Peta harus diunduh, sedangkan Probette tidak pernah terhubung ke internet. Lintang, bujur, dan ketinggian ditampilkan sebagai angka yang dapat Anda salin.

Bagaimana cara menyalakan pratinjau Lihat Cepat di Mac?

Buka Probette sekali. Jika menekan Spasi di Finder masih menampilkan pratinjau biasa, periksa Pengaturan Sistem ▸ Umum ▸ Item & Ekstensi Masuk ▸ Lihat Cepat dan pastikan Probette menyala.

Bagaimana cara menggunakannya dari app lain di iPhone, iPad, atau Android?

Di File, Foto, atau app apa pun yang membagikan file, ketuk Bagikan lalu pilih Probette Info: ringkasannya langsung muncul di situ. Agar file tetap terlihat, buka file tersebut di app Probette dari app File. Di Android, pilih Probette dari Buka dengan atau Bagikan di app mana pun, dan file akan terbuka di Probette.

Beberapa informasi tidak ada atau bertuliskan “Perkiraan”.

Beberapa file tidak mencatat semuanya (aliran MP3 atau AAC mentah tidak memiliki durasi sendiri, jadi durasinya diukur), dan file yang rusak atau belum selesai dibaca sejauh mungkin. Probette menyebutkannya di kartu ringkasan.
